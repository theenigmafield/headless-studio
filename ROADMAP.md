# Roadmap

Headless Studio grows in stages. Each stage should stay useful on its own.

## Now: record (0.1)
- Teleprompter with words-per-minute pacing, breath pauses, countdown, focus, mirror.
- Raw float WAV recording that survives crashes, takes with notes and a starred pick.
- macOS input and output controls.

## Next: prompter polish
- Voice-follow scrolling: the scroll follows your voice (pause when you pause).
- Remote control from a phone or a foot pedal (Bluetooth page-turner keys).
- Second-screen prompter window for a beam-splitter rig.
- Per-script pace memory, and a practice mode that measures your real words per minute.
- Windows and Linux sound controls.

## Later: edit
- Auto-cut a take into lines against the script (word timestamps), pick the best line from any take.
- Clean-up chain: de-click, de-ess, loudness to a target, with before/after A/B.
- Music bed with ducking, and export presets for Reels, Shorts and podcasts.
- Video: record camera alongside audio, then trim, caption and frame for vertical.

## How to help
Open an issue with the "Feature request" template before a large PR so we can agree the shape.
